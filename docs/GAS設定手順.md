# Google Drive自動保存（GAS）設定手順

アプリの撮影データをGoogle Driveに自動保存するための設定です。
**1回だけ**この手順を行えば、以降はアプリから自動でDriveに保存されます。
所要時間：約10分。費用：無料。

## 手順1：Google Apps Scriptプロジェクトを作る

1. 保存先にしたいGoogleアカウントでログインした状態で https://script.google.com を開く
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「姿勢観察アプリ」などに変更（左上の「無題のプロジェクト」をクリック）

## 手順2：コードを貼り付ける

1. エディタに最初から書かれている `function myFunction() {...}` を全部削除
2. このリポジトリの `gas/Code.gs` の中身を**全部コピーして貼り付け**
3. Ctrl+S で保存

## 手順3：ウェブアプリとしてデプロイする

1. 右上の「デプロイ」→「新しいデプロイ」をクリック
2. 歯車アイコン →「ウェブアプリ」を選択
3. 以下のように設定：
   - **説明:** 任意（例：v1）
   - **次のユーザーとして実行:** 自分
   - **アクセスできるユーザー:** **全員**（重要！これにしないとアプリから送信できません）
4. 「デプロイ」をクリック
5. 初回は「アクセスを承認」が求められる → 自分のアカウントを選択 →
   「詳細」→「姿勢観察アプリ（安全ではないページ）に移動」→「許可」
   （自作スクリプトのため警告が出ますが問題ありません）
6. 表示された**ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピー

## 手順4：アプリに設定する

1. 姿勢観察アプリを開く → ホーム画面の「⚙️ 設定」
2. **利用者名** を入力（Driveのフォルダ名になります）
3. **Google Drive連携URL** に手順3でコピーしたURLを貼り付け
4. 「保存」

これで完了です。撮影 →「保存」すると、Google Driveの
`マイドライブ > 姿勢観察アプリデータ > 利用者名 > カテゴリ` に自動保存されます。

## 手順5（推奨）：古い動画の自動削除を設定する

容量節約のため、3ヶ月より古い動画を毎日自動削除する設定です（画像・骨格データは永久保存）。

1. GASエディタの左メニューの時計アイコン（トリガー）をクリック
2. 「トリガーを追加」
3. 以下のように設定：
   - **実行する関数:** `cleanupOldVideos`
   - **イベントのソース:** 時間主導型
   - **時間ベースのタイマー:** 日付ベースのタイマー
   - **時刻:** 午前2時〜3時 など
4. 「保存」

## 評価表QRコード（家族・ケアマネ共有）について

GAS設定が完了すると、以下が使えるようになります：

- **利用者管理:** ホーム画面「👤 利用者を選択」で利用者を追加すると、Driveの「利用者一覧」スプレッドシートに自動登録され、閲覧用トークンが発行されます
- **評価表QR:** 利用者選択画面の「📱 評価表QR」でQRコードを表示。読み込むと評価表ページ（最近の姿勢写真・セラピスト助言・測定値の推移）が開きます
- **閲覧できる人:** QRコード（＝トークン付きURL）を知っている人のみ。家族・ケアマネジャーへはQRを印刷して渡す運用を想定しています
- **クラウド履歴:** 履歴画面の「☁ クラウド」ボタンで、施設のDriveに保存された記録を任意の端末から閲覧できます

※すでにデプロイ済みでコードを更新した場合は、「デプロイを管理」から新バージョンとして再デプロイしてください（下記トラブルシューティング参照）。

## 動作確認

- ウェブアプリのURLをブラウザで開いて `{"status":"ok",...}` と表示されれば、デプロイ成功です
- アプリで撮影 →「保存」→「Google Driveに保存しました ✓」と表示されれば連携成功です

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「Drive送信は失敗」と表示される | ウェブアプリURLが正しいか、「アクセスできるユーザー: 全員」になっているか確認 |
| コードを修正した | 「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」（URLは変わりません） |
| 保存先アカウントを変えたい | 別アカウントで手順1からやり直し、アプリの設定URLを差し替え |
