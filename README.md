# 姿勢観察支援アプリ

スマートフォン・タブレットのカメラで棒人間（スティックフィギュア）を表示し、セラピスト・専門家が姿勢を「目で見て」観察・助言するための支援ツールです。

**アプリを開く:** https://aicaremedi.github.io/posture-observation-app/

## 主な機能

- MediaPipe Poseによるリアルタイム骨格表示（33関節、左右色分け）
- 姿勢観察テンプレート7種 / 動作観察テンプレート5種 / 簡易検査8種
- スクリーンショット撮影（骨格データJSON同時保存）
- 骨格重畳済み動画の録画（WebM）
- 5回立ち上がりテスト（5STS）・CS-30の立ち座り自動カウント
- 棒人間のみ表示モード（プライバシー保護）

## 動作環境

- Chrome / Safari / Edge 最新版
- カメラ利用にはHTTPS接続とカメラ許可が必要です
- 映像はデバイス内で処理され、外部に送信されません
